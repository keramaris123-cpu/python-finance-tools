Το Expense Tracker είναι μια εφαρμογή που βοηθάει στη διαχείριση και καταγραφή των εξόδων.
- Αυτοματοποιεί τη διαδικασία καταγραφής των Εξόδων.
- Υπάρχει δυνατότητα Αναίρεσης/Αφαίρεσης των Καταγραφών Εξόδων.
- Βοηθά στην Οργάνωση των καθημερινών συνολικών Εξόδων ενός ανθρώπου.
- Χρησιμοποιήθηκε μηχανισμός αποθήκευσης JSON (Data Persistence):Υλοποίηση αυτόματης αποθήκευσης (json.dump) και φόρτωσης (json.load) των δεδομένων σε αρχείο .json. Εξασφαλίζει ότι τα έξοδα και οι βάρδιες διατηρούνται στη μνήμη της συσκευής ακόμα και μετά την έξοδο από την εφαρμογή.
- Διαχείριση Σφαλμάτων Αρχείων (Exception Handling): Χρήση try/except (FileNotFoundError) για την ομαλή εκκίνηση του προγράμματος ακόμα και όταν το αρχείο βάσης δεν έχει δημιουργηθεί αρχικά.
